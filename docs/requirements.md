# 要件定義書

## システム概要
このアプリが何をするか：在庫の管理
誰が使うか：在庫管理者

## 画面一覧

| No | 画面名 | ファイル | 主な機能 |
|----|--------|----------|----------|
| ① | 商品一覧画面 | index.html | 在庫アラートバナー、商品一覧、アラート対象のみ表示、CSV ダウンロード |
| ② | 商品登録／入出庫フォーム | form.html | 商品登録、入出庫の記録、現在の在庫一覧 |
| ③ | 商品詳細画面 | detail.html?id=商品ID | 商品詳細、入出庫の記録、商品情報の編集、入出庫履歴、商品の削除 |

画面遷移: ①・②はヘッダーのナビゲーションで切り替える。①の一覧の各行や、アラートバナーの商品名から③へ移動する。

### ① 商品一覧画面（index.html）
- 在庫アラートバナー（C-後半で追加）
  - 一覧の上部に、在庫10未満（threshold = '1'）の商品の件数を「在庫アラート: N 件の商品が在庫10未満です」の形で表示する。
  - 先頭10件は商品名と在庫数を並べ、商品名から詳細画面へ移動できる。11件以上ある場合は「ほか N 件」と表示する。
  - 対象が 0 件のときは何も表示しない。取得に失敗した場合は、一覧の表示を妨げない控えめなエラー文を出す。
  - 初回表示時、「更新」ボタン押下時、ブラウザの「戻る」で戻ってきたときに再取得する。
- 商品一覧
  - 商品ID・商品名・在庫数・アラート（在庫10未満は「在庫少」バッジ）・操作（詳細）を表示する。
  - 1ページ 100 件で、続きは「さらに読み込む」で取得する。
  - 「アラート対象のみ表示」をチェックすると、在庫アラート対象だけに絞り込む。
- CSV ダウンロード（C-後半で追加）
  - 「CSV ダウンロード」ボタンで全商品の在庫一覧を CSV ファイル（products_YYYYMMDD.csv）として保存する。
  - 作成中はボタンが「CSV 作成中…」になり、押せなくなる（二重クリック防止）。
  - 失敗したときは画面を移動せず、画面内にエラーメッセージを表示する。

### ② 商品登録／入出庫フォーム（form.html）
- 商品登録: 商品ID・商品名・在庫数を入力して登録する。在庫アラートは在庫数から自動で判定する。
- 入出庫の記録: 商品を選び、入庫／出庫と数量を入力して記録する。出庫で在庫がマイナスになる場合はエラーにする。
- 現在の在庫一覧: 登録・入出庫に成功すると、自動で再取得する。

### ③ 商品詳細画面（detail.html?id=商品ID）
- 商品詳細: 商品ID・商品名・在庫数・在庫アラートを表示する。
- 入出庫の記録: この商品に対する入庫／出庫を記録する。
- 商品情報の編集: 商品名・在庫数を更新する（変更した項目だけを送る）。
- 入出庫履歴: この商品の履歴を表示する（1ページ 100 件、続きは「さらに読み込む」）。
- 商品の削除: 画面内で確認してから削除する。入出庫履歴がある商品は削除できない。


## APIエンドポイント一覧

| メソッド   | パス                      | 概要                    |
| ------ | ----------------------- | --------------------- |
| GET    | /products               | 商品一覧を取得する             
| GET    | /products/:id           | 商品詳細を取得する             
| POST   | /products               | 商品を登録する               
| PUT    | /products/:id           | 商品情報（商品名・在庫数・閾値）を更新する 
| DELETE | /products/:id           | 商品を削除する               
| GET    | /products/alerts        | 在庫数が閾値を下回った商品一覧を取得する  
| POST   | /stock-transactions     | 入庫・出庫を記録する            
| GET    | /stock-transactions     | 入出庫履歴一覧を取得する          
| GET    | /stock-transactions/:id | 入出庫履歴詳細を取得する          


## DBテーブル設計
（テーブル名・カラム名・型・制約）
①物理名：M_PRODUCTS　論理名：商品マスタ
| 論理名   | カラム名             | 型           | 制約                |
| -------- | -------------        | ------------ | ------------------- |
| 商品ID   | product\_id          | VARCHAR(10)  | PRIMARY KEY         |
| 商品名   | product\_name        | VARCHAR(100) | NOT NULL            |
| 在庫数   | stock                | INTEGER      | NOT NULL, DEFAULT 0 |
| 在庫アラート閾値 | threshold    | VARCHAR(1)   | NOT NULL            |



②物理名：T_STOCK_TRANSACTIONS 論理名：入出庫履歴
| 論理名  | カラム名          | 型          | 制約                  |
| ----    | ----------------- | ----------- | --------------------- |
| 履歴ID  | rireki\_id        | VARCHAR(10) | PRIMARY KEY           |
| 商品ID  | product\_id       | VARCHAR(10) | NOT NULL, FOREIGN KEY |
| 取引種別| transaction\_type | VARCHAR(1)  | NOT NULL              |
| 数量    | quantity          | INTEGER     | NOT NULL              |



## 状態遷移（該当するテーマのみ）
（ステータスがどう変化するか）
①在庫アラート閾値
0：在庫10以上
1：在庫が10未満の状態 

②取引種別
0：入庫
1：出庫
