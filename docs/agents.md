# Subagent定義

## backend-architect

- 役割：
  - バックエンドAPIおよびDB設計・実装を担当する

- 担当するタスク：
  - APIエンドポイント設計
  - 商品CRUD機能実装
  - 入出庫記録機能実装
  - 在庫アラート機能実装
  - PostgreSQLテーブル作成およびマイグレーション作成

- 特に注意させること：
  - REST API設計に従うこと
  - 在庫数がマイナスにならないようチェックすること
  - SQLインジェクション対策としてパラメータ化クエリを使用すること
  - 入出庫時に商品在庫を正しく更新すること

## frontend-developer

- 役割：
  - フロントエンド画面の設計・実装を担当する

- 担当するタスク：
  - 商品一覧画面（index.html）の実装
  - 商品登録／入出庫画面（form.html）の実装
  - 在庫アラート表示機能実装
  - 入出庫履歴表示機能実装
  - fetch APIによるバックエンド連携

- 特に注意させること：
  - バニラHTML/CSS/JavaScriptで実装すること
  - 入力値の必須チェックを行うこと
  - API通信失敗時のエラーメッセージを表示すること
  - 操作しやすいUIを意識すること

## security-auditor

- 役割：
  - システム全体のセキュリティおよび品質レビューを担当する

- 担当するタスク：
  - APIの入力値検証確認
  - SQLインジェクション対策確認
  - XSS対策確認
  - エラーハンドリング確認
  - コードレビューおよび脆弱性チェック

- 特に注意させること：
  - OWASP Top 10を意識してレビューすること
  - 入力値を必ずバリデーションすること
  - 機密情報をソースコードへハードコードしないこと
  - フロントエンド出力時にエスケープ処理を確認すること
